# Исполняемый Linux-контур продуктового загрузчика (`TMXMapLoader.swift`)

Зачем: до этого прогона потолком Linux-валидации считался `swiftc -frontend -parse`
(синтаксис без типов). Здесь доказывается больше: **разбор 125 уровней выполняет сам
продуктовый Swift-код**, а не python-реплика, и поведение загрузчика на битых данных
наблюдается исполнением, а не чтением.

## Состав

| Файл | Что это |
| --- | --- |
| `run.sh` | сборка и прогон; fail-closed (нет стаба/исходника/тулчейна — нерабочий код не выполняется) |
| `coregraphics_shim.swift` | 1 строка: `@_exported import Foundation` — даёт модуль `CoreGraphics` из `Foundation` на Linux |
| `gen_fixtures.py` | 17 malformed-карт (чужой корень, пустой `<map/>`, gzip/zlib, опечатка в числе, утечка свойств, обрезанный/лишний base64, huge dims, layer без data и т.д.) |
| `main.swift` | прогон фикстур + всего корпуса + геометрия зоны 009 |
| `last-run.txt` | вывод прогона на HEAD `52795d1` (проскрабленный), `REAL MAPS ok=125/125 failures=0` |
| `fixtures/` | генерируется, в git не входит |

## Запуск

```bash
./run.sh                      # из каталога harness/
./run.sh | tee last-run.txt   # обновить артефакт прогона
```

На macOS скрипт намеренно отказывается работать (`rc=75`) — там нужно собирать настоящий
таргет (`xcodebuild -project Exolon.xcodeproj -target Exolon -configuration Debug build`),
и этот контур только хуже имитировал бы сборку.

## Что именно гарантирует честность замера

- Продуктовый файл **не** правится: в сборочный каталог кладётся копия, в которую `awk`
  вставляет ровно одну строку `import FoundationXML` после `import CoreGraphics`;
  проверка `sed '2d'` обязана вернуть файл к репозиторному байт-в-байт, иначе `rc=65`.
- Негативный контроль: та же сборка **без** стаба обязана упасть (`no such module
  'CoreGraphics'`), иначе вывод выше нечем отличить от самообмана.
- Это по-прежнему **не** type-check всего проекта и **не** сборка: `Player`/`GameScene`
  и любой код, зависящий от SpriteKit, в контур не входит.

## Что этот контур уже опроверг или подтвердил

- подтвердил B-04a: `compression="zlib"`/`gzip` → `throw`, а в продукте за ним стоит
  `fatalError` в `TMXLevelRuntime.swift:53` (в данных корпусов сжатия нет ни у одного слоя);
- подтвердил B-04b: пустой/чужой корень загружается как «играбельная пустота»;
- подтвердил B-04c: опечатка `y="17o"` молча становится `0`;
- показал новую вещь: свойства из `imagelayer`/`objectgroup` утекают в свойства карты, а из
  `layer`/`tileset` — молча теряются;
- выдал геометрию зоны 009 (`capsule x=368 y=176 w=32 h=80 mode=tiledRect →
  bottomLeft=(368,128) pixelH=384`), на которой держится снятие прежнего P0 (C1).
